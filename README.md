## Overview

This is a responsive article-preview component with an accessible, keyboard-operable share disclosure. The active implementation is the vanilla TypeScript/Vite app in `frontend/`.

### The job

Users should be able to:

- View the optimal layout for the component depending on their device's screen size
- See the social media share links when they click the share icon
